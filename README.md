# 데이톨로지 강의자료

데이터를 과학과 인문학의 두 관점으로 읽는 15주 교양 강의의 웹 슬라이드입니다. 과거(데이터와 인류 문명) → 현재(별점·알고리즘·메타버스·특이점) → 미래(딥필링)의 흐름을 따라갑니다.

## ▶ 바로 보기

**https://ogwany-crypto.github.io/datalogy-lecture/**

목록 페이지에서 강의를 고르면 해당 강의 슬라이드 첫 장이 열립니다. 설치 없이 브라우저만 있으면 됩니다.

## 슬라이드 조작

| 키 | 동작 |
|---|---|
| ← → · Space · 클릭 | 이전 / 다음 슬라이드 |
| F | 전체 화면 |
| N | 발표자 노트 (출처·검증 메모 포함) |
| 영상 클릭 | 애니메이션 다시 재생 |

화면 크기에 맞춰 1920×1080 무대가 자동으로 확대·축소되고, 주소의 `#번호`로 특정 슬라이드에 바로 갈 수 있습니다.

## 구성

- **주교재:** 김성태, 『데이톨로지 — AI·메타버스 시대를 읽는 데이터인문학』, 이른비, 2022
- **대상:** 대학 교양(전 학년, 전공 무관)
- **분량:** 15주(16주차는 기말), 강의마다 슬라이드 15~23장
- **강의마다 세 가지 페이지**
  - **슬라이드:** 개념마다 [비유] 사진 슬라이드 → manim 애니메이션 슬라이드, 정리, 확인 문제(정답 보기)
  - **웹 퀴즈:** 8~10문제, 바로 채점과 해설
  - **놀이터:** 슬라이드의 애니메이션을 직접 조작하는 시뮬레이션

강의 내용은 책 소개와 저자의 지디넷코리아 연재 「김성태의 데이톨로지」(2021) 12편을 바탕으로 재구성했습니다.
