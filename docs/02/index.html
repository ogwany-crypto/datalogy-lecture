오늘의 질문

1만 개가 넘는 지명을 담은 지도,

짝과 1분 추측. 흔한 답 “전국을 직접 걸었다” → 2-1에서 반전(기존 자료의 통합).
2-1

김정호와 『대동여지도』

[비유] 퍼즐 조각

사진: Electric-Eye / CC BY 2.0

퍼즐 조각 = 흩어진 지리 자료

  • 조각 하나 = 지도 한 장, 지리서 한 권, 구전 한 마디
  • 조각만으로는 전체 그림 불가
  • 맞추는 기준 = 방안좌표와 표준 기호
  • 완성된 그림 = 한 장의 전국 지도
2-1

김정호와 『대동여지도』

수집 → 편집(방안좌표) → 표준화(같은 기호)

manim: 출처 4종의 점이 방안좌표에 놓이고 같은 기호로 바뀜. 연재 ①: 직접 답사보다 중앙정부 지도·지리서, 지방 관청 문서, 보부상·짐꾼 구전의 통합. 그림 속 지형은 개념도(실제 지도 아님).
2-1

김정호와 『대동여지도』

숫자로 본 대동여지도

1861 · 철종 12년

구성

  • 남북 22판, 동서 19판
  • 접고 펼치는 구조
  • 산줄기·물줄기·고을·도로

거리와 지명

정밀도

  • 10리(약 4km)마다 점
  • 지명 약 1만 1,680개
  • 축척 약 1:16만~1:21.6만 (추정)

평가

“첨단지도”

  • 단순한 고지도 이상
  • 누구나 읽는 표준 기호
  • (민병준의 평가)
출처: 연재 ①(2021.05.10). [검증 노트] 칼럼은 축척을 “약 16만분의 1”과 “1:216,000”으로 함께 적음 → 연구자마다 추정치가 달라 범위로 표기. 지명 수는 민병준 해설서 기준.
2-2

매튜 머리와 항해도

[비유] 바다의 지도, 해도

사진: NOAA's National Ocean Service / CC BY 2.0

해도 = 항해일지 데이터의 결정체

  • 선박 한 척의 일지 = 바다의 한 줄 기록
  • 수많은 일지를 겹치면 바람·해류의 패턴
  • 패턴 위에 그린 선 = 더 빠르고 안전한 항로
  • 창고 속 종이 더미 → 바다의 길잡이
2-2

매튜 머리와 항해도

항해일지 50만 건 이상 → 바람·해류 → 새 항로

manim: 기록 수 카운터 → 바람·해류 화살표 → 기존 항로(회색) vs 데이터로 찾은 항로(빨강). 바다·항로 모양은 개념도. “50만 건 이상”은 연재 ① 수치.
2-2

매튜 머리와 항해도

사고에서 시작된 데이터 여정

1825 → 1842

위기

  • 미 해군 장교로 입대
  • 마차 사고로 현장 복귀 불가
  • 해도측기창 배치, 창고 속 자료 정리

분석

데이터

  • 바다 날씨·기후, 시기별 기상
  • 해류·암초 위치, 과거 사고
  • 50만 건 이상의 기록

1853 · 1855

성과

  • 안전하고 빠른 항해도·항적도
  • 브뤼셀 국제해양기상회의 (세계기상기구의 전신)
  • 대서양 해저케이블 제안
출처: 연재 ①. 1855년 저서 『바다의 자연지리학(The Physical Geography of the Sea)』. 연재는 멕시코만·카리브해 사고 데이터 분석으로 대서양의 따뜻한 해류를 “처음 발견”했다고 서술 — 해류 발견사는 다른 기록도 있으므로 강의에서는 “데이터로 확인·정리”로 표현.

창조는 편집이다

[비유] 모자이크

사진: Scott 97006 / CC BY 2.0

모자이크 = 편집

  • 타일 하나하나 = 이미 있던 조각
  • 새 타일을 만들지 않아도 새 그림
  • 가치 = 조각의 배치와 연결
  • 김정호·머리 = 남의 기록으로 새 지도
2-3

창조는 편집이다

에디톨로지와 패러다임 시프트

manim: 흩어진 타일이 하나의 무늬로 재배치. 연재 ①: 토머스 쿤의 패러다임 시프트, 김정운의 에디톨로지. [검증 노트] 칼럼 표기 “에티톨로지” = 김정운 『에디톨로지』(2014).
2-3

창조는 편집이다

두 사람의 같은 방법

단계김정호 (1861)매튜 머리 (1840~50년대)
수집정부 지도·지리서·관청 문서·구전창고 속 항해일지·사고 기록
편집방안좌표로 비율 맞추기시기·위치별 바람·해류 정리
표준화기호·선·점의 규격화항해도·항적도 양식
가치누구나 읽는 전국 지도빠르고 안전한 항로, 국제 기상 협력
강의자 정리표(연재 ① 내용을 4단계 틀에 배치). 결론: 완전히 새로운 것은 드묾, 흩어진 데이터를 통합하는 능력이 핵심 역량.

토론 질문

활동 · 정리 및 확인 문제

오늘의 핵심 4줄

김정호 = 기존 자료의 통합 + 방안좌표 + 표준 기호 → 대동여지도

매튜 머리 = 항해일지 50만 건 이상 → 바람·해류 패턴 → 새 항로

공통 방법 = 수집 → 편집 → 표준화 → 가치 발견

메시지 = 창조는 편집, 흩어진 데이터를 잇는 능력
