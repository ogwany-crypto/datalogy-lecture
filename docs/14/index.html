지능에서 감정으로

[비유] 계단

사진: Gareth1953 All Right Now / CC BY 2.0

계단 = AI 발전 단계

  • 한 칸씩 올라야 닿는 위층
  • 첫 칸 = 딥러닝 (외면 인식)
  • 둘째 칸 = 딥언더스탠딩 (맥락 이해)
  • 맨 위 = 딥필링 (감정 메커니즘)
14-1

지능에서 감정으로

딥러닝 → 딥언더스탠딩 → 딥필링

manim: 저자가 연재 ⑪(2021.08.18)에서 제안한 AI 발전 3단계. 딥러닝 = 외면(이미지 인식 등), 딥언더스탠딩 = 사회적 맥락, 딥필링 = 감정 메커니즘 학습.
14-1

지능에서 감정으로

왜 감정인가

“미래사회의 인공지능 기술은 인간의 복잡한 감정을 이해하고, 그 작동 메커니즘을 얼마나 완벽하게 구현하느냐에 달려 있다.”김성태, 『데이톨로지』 p.223

영화로 본 변화

  • 「터미네이터」: 감정 없는 기계의 공포
  • 「그녀(Her)」: 감정을 나누는 기계와의 사랑
  • AI의 목표: 지능 이식 → 감정 주입
  • 딥러닝 AI의 한계: 결과는 내지만 감정 이해·반응 부족
출처: 예스24 책 소개 발췌(p.223), 브레인미디어 책 소개(터미네이터·그녀), 연재 ⑫.
14-2

감정을 둘러싼 사상사

[비유] 마차와 마부

사진: archer10 (Dennis) / CC BY-SA 2.0

마부 = 이성, 말 = 감정

  • 플라톤의 오래된 그림: 마부가 말을 다스리는 마차
  • 이성 우위 전통의 출발점
  • 질문: 말 없이 마차가 움직일 수 있을까?
  • 근대 이후: 말(감정)이 마차를 움직이는 힘이라는 발견
[보충] 플라톤 『파이드로스』의 마부 비유는 강의자 보충(책 본문 확인 필요). 책은 소크라테스·데카르트·니체·다마지오 등을 다룸(지디넷 출간 기사, 브레인미디어).
14-2

감정을 둘러싼 사상사

“이성이 감정을 다스림” → “감정이 이성의 토대”

manim: 사상가를 시간순으로 놓고 무게중심이 이성 → 감정으로 이동. 흐름 요약은 강의자 [보충].
14-2

감정을 둘러싼 사상사

사상가별 감정관 (요지)

소크라테스·플라톤이성이 감정(욕구·기개)을 다스려야 함 — 이성 우위의 전통
데카르트『정념론』: 정념 = 몸과 마음의 상호작용 · 무의식의 기억이 불쑥 떠오르는 ‘상기’
니체이성 중심 철학 비판 · 충동·정동이 사유의 바탕
프로이트무의식이 정신의 90% 이상 · 자각하지 못하는 영역이 감정을 만듦
다마지오『데카르트의 오류』 신체 표지 가설 · 감정 없이는 합리적 판단도 불가
[보충] 인물 목록은 원전(출간 기사·연재 ⑫), 각 요지는 강의자 정리. 데카르트의 ‘상기’, 프로이트 90%는 연재 ⑫·⑪에서 인용. 책 3부 본문과 대조 필요.

기계는 이해할 수 있는가

[비유] 말하는 앵무새

사진: Charles Patrick Ewing / CC BY 2.0

앵무새 = 흉내 내는 AI

  • “안녕하세요”를 정확히 따라 하는 새
  • 소리는 같아도 뜻을 아는지는 미지수
  • 타인의 말·행동을 학습해 마음을 흉내 내는 AI
  • 흉내 ≠ 자의식으로 느끼고 행동하는 인간
앵무새 비유는 강의자 구성. 저자 입장(흉내 내는 AI ≠ 자의식의 인간): 지디넷 출간 인터뷰(2022.08.29).
14-3

기계는 이해할 수 있는가

중국어 방(Chinese Room) 논증: 규칙 따른 기호 조작 ≠ 이해

manim: 중국어를 모르는 사람이 규칙서만 보고 올바른 답을 내보냄 → 밖에서는 이해하는 것처럼 보임. 존 설(1980). 연재 ⑫에서 인용.
14-3

기계는 이해할 수 있는가

논쟁과 기술의 현재

논쟁

중국어 방 이후

  • 커즈와일: 시스템 반론
  • 래퍼포트: ‘한국어 방’(1988)
  • 데닛: 완벽한 시스템 가정

기술

뇌를 닮으려는 시도

  • 뉴로모픽 반도체 (삼성전자·하버드)
  • 뉴럴링크 시연 (2020.8)
  • 베리칩 논쟁

경고

마음의 자살?

  • 수전 슈나이더: 뇌-컴퓨터 결합 = 마음의 자살 가능성
  • 사랑에 빠지는 순간 = 학습 너머의 본능
출처: 연재 ⑫(2021.09.27) — 커즈와일·래퍼포트·데닛, 뉴로모픽, 뉴럴링크, 베리칩. 출간 인터뷰(2022.08.29) — 슈나이더, 사랑에 빠지는 순간.

딥필링의 정의

[비유] 빙산

사진: NOAA's National Ocean Service / CC BY 2.0

빙산 = 인간의 마음

  • 물 위 = 의식 (약 10%)
  • 물 아래 = 무의식 (약 90%, 프로이트)
  • 감정은 물 아래에서 먼저 움직임
  • 물 위만 보는 AI = 감정의 일부만 학습
프로이트의 빙산(의식 10% : 무의식 90%)은 연재 ⑪(2021.08.18)에서 저자가 인용.
14-4

딥필링의 정의

잠재 기억 · 지능 · 감정 · 외부 상황의 순간 결합

manim: 의식·무의식 선 위아래의 네 요소가 한 점에서 결합 = 딥필링. 정의는 연재 ⑫(2021.09.27).
14-4

딥필링의 정의

딥필링 · 인공감정지능

딥필링(Deep Feeling)

무의식의 감정이 기억으로 소환되거나 생각할 틈 없이 본능적 ‘촉’이 먼저 작동하는 순간, 잠재 기억 · 지능 · 감정 · 외부 상황이 순간적으로 결합해 만드는 감정의 메커니즘

인공감정지능(Artificial Emotional Intelligence)

감정을 이해하고 반응하며 사람과 감정적으로 교류하는 인공 시스템

기존 측정의 한계: 자기보고식 설문·뇌파 같은 생리 측정만으로는 설명 불가

출처: 연재 ⑫(2021.09.27). 책 3부에서 딥필링의 작동 원리와 구현 이론을 더 다루므로 본문 확인 필요.

정리 및 확인 문제

활동 (60분): 감정은 학습 가능한가 — 소크라테스 대화

STEP 1 · 개인 10분

나의 ‘촉’

  • 이유 없이 끌렸던 경험 하나 적기
  • 결합한 것: 기억·지식·감정·상황

STEP 2 · 소그룹 30분

문답법

  • 한 명: “AI도 할 수 있음” 주장
  • 나머지: 질문만으로 검토

STEP 3 · 실험 20분

챗봇 공감 실험

  • 같은 슬픈 사연, 다른 말투로 입력
  • 공감인가, 공감의 시뮬레이션인가
강의안 14주차 활동. STEP 3은 11주 보드리야르의 시뮬라시옹과 연결.

정리 및 확인 문제

오늘의 핵심 4줄

AI 3단계 = 딥러닝 → 딥언더스탠딩 → 딥필링

사상사 = 이성 우위 → 감정이 판단의 토대

중국어 방 = 기호 조작 ≠ 이해, 흉내 ≠ 느낌

딥필링 = 잠재 기억·지능·감정·상황의 순간 결합

14-5

정리 및 확인 문제

확인 문제

문제 1

저자가 제안한 AI 발전 3단계와 각 단계가 다루는 것

문제 2

중국어 방 논증이 보여 주려는 것

문제 3

딥필링을 이루는 네 요소와, 설문·뇌파만으로 설명하기 어려운 이유

문제 1: 딥러닝(외면 인식) → 딥언더스탠딩(사회적 맥락 이해) → 딥필링(감정 메커니즘 학습)
문제 2: 규칙에 따라 기호를 조작해 올바른 답을 내도, 그것이 이해는 아님
문제 3: 잠재 기억·지능·감정·외부 상황 / 무의식과 ‘촉’이 생각할 틈 없이 순간적으로 결합하기 때문
정답 — 1: 연재 ⑪. 2: 존 설(1980), 연재 ⑫. 3: 연재 ⑫.
